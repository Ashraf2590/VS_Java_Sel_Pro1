Rest Assured sample project

This is a minimal Maven project that demonstrates a simple API test using Rest Assured and JUnit 5.

Run the test from the project root:

```cmd
cd "C:\\Users\\DELL\\Desktop\\VS_Java_Sel_Pro1\\rest-assured-sample"
mvn test
```

The test calls https://jsonplaceholder.typicode.com/posts/1 and asserts the response.
